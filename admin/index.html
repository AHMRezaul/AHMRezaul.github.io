Connect to GitHub

This page edits the JSON files in your site's repository and saves each change as a commit. Nothing works without your personal access token, which is stored only in this browser.

How do I create a token?
  1. GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Repository access: Only select repositories → choose your site repo.
  3. Permissions → Repository permissions → Contents: Read and write. Nothing else is needed.
  4. Set an expiry, generate, and paste the token above.

Use this only on your own device. Sign out when done on a shared computer.
